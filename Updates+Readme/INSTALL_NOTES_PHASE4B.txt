SONARQUBE PHASE 4B — SUDOKU WORDLY-SAFE FIX PACK

Built on top of Phase 4A.

Scope:
- js/games/sudoku.js only.

What changed:
- Refactored Sudoku input handling into smaller pen/pencil helpers.
- Refactored conflict checks into row, column, and box helpers.
- Refactored render into grid, cell, class, note, and event helpers.
- Refactored pane setup and key handling into smaller named handlers.
- Preserved the public GameSudoku API used by popup.js.
- Preserved Wordly, Contexto, history.js, and all previous Phase 1–4A fixes.

Install:
1. Extract this zip into your extension root folder.
2. Choose Replace files in destination.
3. Reload the unpacked extension.

Regression tests:
1. Confirm Wordly opens.
2. Confirm Contexto opens.
3. Open Sudoku.
4. Start Easy, Medium, and Hard games.
5. Select cells with mouse.
6. Enter values using keyboard 1-9 and the numpad buttons.
7. Press P to toggle Pencil mode.
8. Right-click a cell and confirm Pencil mode turns on.
9. Add and clear notes.
10. Use Delete, Backspace, or 0 to clear a selected editable cell.
11. Use arrow keys to move selection.
12. Confirm fixed cells cannot be edited.
13. Re-run SonarQube.
