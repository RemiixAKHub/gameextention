SONARQUBE PHASE 3E — CONNECT 4 / MARBLE RUN / TRAFFIC JAM LOW-RISK CLEANUP

Install:
1. Extract this zip into the extension root folder.
2. Choose "Replace files in destination".
3. Reload the unpacked extension in the browser extension page.

This pack is built on top of Phase 3D and keeps:
- Wordly
- Contexto
- history.js / Solitaire undo support
- Phase 1 safe cleanup
- Phase 2 CSS cleanup
- Phase 3A Blackjack / Picture Poker / Tetris cleanup
- Phase 3B Solitaire / History cleanup
- Phase 3C Yahtzee cleanup
- Phase 3D small-game cleanup

Phase 3E targeted files:
- js/games/connect4.js
- js/games/marblerun.js
- js/games/trafficjam.js

Regression checks:
1. Reload unpacked extension.
2. Confirm Wordly opens.
3. Confirm Contexto opens.
4. Connect 4: move cursor, drop a piece, allow AI move, reset.
5. Marble Run: select marble, select wager, start single race, tournament if desired.
6. Traffic Jam: open level select, load a level, drag cars, use arrow-key movement after selecting a car, reset, return to level select.
7. Re-run SonarQube.
