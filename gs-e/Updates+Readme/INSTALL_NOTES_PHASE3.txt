SonarQube Phase 3A — Low-risk JS maintainability

Install:
1. Extract this zip into your extension root folder.
2. Choose Replace files in destination.
3. Reload the unpacked extension.

This pack is built on top of Phase 2 and preserves:
- Wordly wiring
- Contexto wiring
- history.js / Solitaire undo support
- Phase 1 safe JS fixes
- Phase 2 CSS fixes

Phase 3A scope:
- js/games/blackjack.js
- js/games/picpoker.js
- js/games/tetris.js

Changes:
- Blackjack: optional-chain load guard, removed unused clearBetAction wrapper, fixed Clear so it clears the staged bet without incorrectly adding chips, extracted hand-value label formatting.
- Picture Poker: optional-chain load guard, extracted hand-result resolution to remove redundant winnings assignment.
- Tetris: optional-chain load guard, split render and keyboard logic into smaller helpers to reduce cognitive-complexity findings while preserving behaviour.

Validation performed:
- node --check passed for every JS file included in the pack.
