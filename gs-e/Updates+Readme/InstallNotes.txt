## General installation pattern

Unless a phase states otherwise:

1. Extract the relevant overlay into the extension root.
2. Replace files when prompted.
3. Reload the unpacked extension.
4. Run the listed regression checks.
5. Re-run SonarQube where requested.

## Preservation rule

Later packs are described as overlays built on top of earlier phases. Their
notes repeatedly preserve Wordly, Contexto, Solitaire history/undo support and
earlier completed SonarQube fixes unless a phase explicitly states otherwise.

Combined Games Extension — Wordly + SonarQube Phase 1 Safe Fix Pack

This pack replaces the earlier Wordly/Sonar pack and keeps Wordly wired in.

- popup.css with Wordly styles preserved, Traffic Jam duplicate CSS removed, #tab-bar selector merged, and Picture Poker font fallback fixed.
- Phase 1 safe Sonar fixes for current game files.

Phase 1 fixes:
- Replaces game Math.random() usage with crypto.getRandomValues-backed helpers in affected game files.
- Removes/wires small unused or redundant code flagged by Sonar.
- Replaces simple bare Array() patterns flagged by Sonar.
- Uses structuredClone for Solitaire snapshots.
- Replaces nested Minesweeper template literal.
- Adds handled logging to Traffic Jam catch blocks.

Not included:

- No high-cognitive-complexity refactors yet.

Install:
1. Copy the contents of this zip into your extension root folder, preserving paths.

5. Open every game once.
