Install:
1. Copy this pack into your extension root folder, preserving paths.
2. Replace files when Windows asks.
3. Reload the unpacked extension.
4. Confirm Wordly and Contexto still appear.
5. Open Traffic Jam, Marble Run, Picture Poker, Contexto, and Wordly to check visual display.
